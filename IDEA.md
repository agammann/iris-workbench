# Project idea

IRIS administration often requires switching between configuration, permissions and logs while remembering the object being investigated. IRIS Workbench keeps a selected object's context in an inspector beside its list and provides a common review step before writes.

The core journey is to inspect an application, examine its settings and access requirements, find relevant audit evidence, review the fields to change, apply the change, and verify the result from IRIS. The same interaction extends to users, roles, security configuration and scheduled tasks.

The visual direction was selected from three original concepts after a curated review of 100 public product and design pages. Its charcoal palette, restrained amber actions, horizontal navigation and table beside inspector layout are implemented as native React controls.

This project does not claim automated root cause analysis, automatic repair or rollback. Its value is legible information, deliberate changes, and truthful result reporting across the required management areas.
